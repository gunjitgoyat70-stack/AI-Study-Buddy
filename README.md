# AI Study Buddy

A responsive frontend student dashboard built with HTML, CSS and JavaScript.

## Features
- Responsive dashboard layout
- Demo study assistant with prepared responses (not a live AI API)
- Study planner with tasks saved in browser localStorage
- Five-question quiz with score tracking
- Progress snapshot

## Run locally
Open this folder in Visual Studio Code. Install the Live Server extension, then right-click `index.html` and choose **Open with Live Server**.

## Deploy
Push the three website files to a public GitHub repository, then import that repository into Vercel. Use Framework Preset **Other**, leave Build Command blank, and set Output Directory to `.`.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — interactions and browser storage
